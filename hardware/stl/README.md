# BN-USV V2 STL files

These STL files describe the prototype hull and related parts. The design is still being improved for printability, assembly and watertightness; check the models in a slicer and test-fit the parts before use.

## Module arrangement

The vessel consists of **one Main module** and **two Sub modules**. Print two sets of the same Sub module STL models and arrange them symmetrically on the left and right sides of the Main module. The two sides use the same models; separate left- and right-hand STL files are not required.

| Folder | Contents |
| --- | --- |
| `Main Module/` | Main housing, cover and axis support. |
| `Sub Mid/` | Middle Sub housing and cover. |
| `Sub FWD & AFT/` | Forward/aft Sub housing and cover, plus thrust module parts. |
| `Connection/` | Module connection parts. |
| `Weight pallet/` | Main and Sub weight pallet parts and related tools. |

## Weight pallets

Print the weight pallet models in the quantities needed for your own layout. The pallets have holes for attachment to the bottom of the Main and Sub housings. If additional height is needed, use the extension in `Weight pallet/Tools/` to raise the assembly.

## Before printing and use

Print orientation and support requirements depend on the part and slicer settings. These are prototype models and some parts may need supports or further design changes. Check fit and enclosure sealing, particularly around inserts and cable entries, before use on water.
