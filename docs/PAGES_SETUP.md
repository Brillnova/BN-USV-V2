# GitHub Pages setup

The combined English V2 and V1 project page is `index.html` in this folder. Open it locally in a browser to preview it. The page is static; it does not operate the vessel.

After the V2 GitHub repository exists, in its Settings → Pages choose deployment from a branch, the intended branch, and the `/docs` folder. Save and use the URL reported by GitHub. The page and its images, stylesheet and icons must remain together in `docs/`.

Before publishing, verify the V2 video link, add the actual repository link when known, confirm image rights and retain the separate software and STL license notices. This preparation does not create a repository or publish the page.
