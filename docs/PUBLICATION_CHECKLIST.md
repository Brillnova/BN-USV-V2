# Publication checklist

Review these items when updating this public repository:

1. Review the selected files and decide what mechanical interfaces, CAD, PCB designs or images, if any, should be disclosed. Review patent strategy before any additional public disclosure.
2. Choose and add the owner-approved V2 license. Do not assume V1 terms apply. Keep third-party notices.
3. Review source, history and generated assets for credentials, identifying network details, device IDs, location data and other private information. This folder has no project Git history.
4. Check hardware pin assignments, ADC dividers, dependencies and build instructions against the hardware being shared. Sensor settings in this copy are neutral examples and require per-vessel calibration.
5. Verify the demo, firmware builds, safety behavior and documentation. Clearly retain the prototype and field-test limitations.
6. Add any approved video link or images and verify rights and attribution.

Excluded: local secrets, network configuration, field calibration files, real mission plans and logs; original CAD and PCB manufacturing files; working notes, generated media and local environments.
